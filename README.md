## 글과 디자인 수정
- `index.html`: 블로그 이름, 소개, 메인 화면
- `app.js`: posts 배열의 글 내용과 카테고리
- `style.css`: 색상, 글꼴, 화면 배치

빌드 과정 없는 HTML/CSS/JS입니다. Markdown 자동 변환 기능은 포함하지 않습니다.
GitHub Pages가 main 브랜치의 루트(/)에서 배포합니다. 변경 사항을 커밋하면 자동 반영됩니다.
`.nojekyll`은 Jekyll 변환 없이 파일을 게시하도록 합니다.

로컬 확인: `python3 -m http.server 8080`
